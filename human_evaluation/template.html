Before you begin

Answer independently using PHREEQC 3.8.6 with the phreeqc.dat file provided with this worksheet. Do not use the phreeqc.dat installed with PHREEQC; it is a different file and gives different numbers. Documentation and a calculator are allowed; do not use LLM assistants, answer keys, or other participants’ answers.

Each scenario shares a simulation setting. You may reuse your own simulation within a scenario. Keep your input and output files in one folder per scenario, named by its scenario ID (for example S02), and send them separately to the organizer. This page records answers; it does not execute PHREEQC.

Choose A–D, or E — I don’t know. E is an abstention, not an extra scientific answer; it is distinct from a blank response and from any original “N/A” option. No correctness feedback is shown. You can change answers until finalization.

If you think a question is flawed (missing information, no correct option, more than one correct option, unclear wording), still choose your best answer or E, then switch on Report a problem and pick a reason. A short note helps. Reports go to the question author and do not change your score.

Progress is saved in this browser when storage is available. Keep using the same file location and browser, and download backups. When finished, download the final JSON and send it to the organizer; nothing is uploaded automatically. Follow the organizer’s separate consent instructions.
